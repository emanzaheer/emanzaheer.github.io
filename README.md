# EmanZaheer — Portfolio website

A responsive, playful editorial portfolio built with HTML, CSS and vanilla JavaScript.

## Open the website
1. Extract the ZIP file.
2. Keep the `eman_portfolio` folder and its `assets` folder together.
3. Open `index.html` in a browser.

## What's included
- EmanZaheer branding and personal introduction.
- Description-first project cards. Select **Explore project** to open an animated case-study modal.
- Saheli case study with the two supplied boards of actual app screens.
- Queendom and Morsify screenshots inside their project details.
- Reserved image areas inside project details for screenshots you may add later.
- About, experience, education, toolkit and contact sections.

## Add more project images later
Open `index.html` and find the relevant project entry in `script.js`. Each project has a `placeholder` field for its future screenshots. To show images instead, add image files to `assets/` and replace the project's `placeholder` field with `gallery` and `galleryAlt` arrays, following the Saheli or Queendom example.
